# Codex App かんたん切り替え 操作マニュアル

## このアプリでできること

ターミナルやコマンドを使わず、次の操作ができます。

- 通常のCodex GPTでCodex Appを使う
- インストール済みのOllamaモデルからCodex対応モデルを選ぶ
- Ollamaモデルをインストール・確認する
- 各モデルのOllama公式ページを開き、モデル名やコマンドをコピーする

## 事前準備

1. Codex Appをインストールします。
2. Ollama v0.24.0以降をインストールします。
3. Cloudモデルを使う場合はOllamaへサインインします。

## ダウンロード

最新版の配布ページ:

- [GitHub Releasesから最新版を選ぶ](https://github.com/aikiti/codex-app-easy-switcher/releases/latest)
- [Mac版（公開済みv0.4.0）を直接ダウンロード](https://github.com/aikiti/codex-app-easy-switcher/releases/download/v0.4.0/Codex-App-Easy-Switcher-macOS.zip)
- [Windows版EXE（公開済みv0.4.0）を直接ダウンロード](https://github.com/aikiti/codex-app-easy-switcher/releases/download/v0.4.0/Codex-App-Easy-Switcher-Windows.exe)

## macOSでの起動方法

1. `Codex App かんたん切り替え.app`をダブルクリックします。
2. 初回起動時に警告が表示された場合、アプリを右クリックして「開く」を選びます。
3. 初回切り替え時にCodex Appを制御する許可を求められた場合は許可します。

## Windowsでの起動方法

1. `Codex-App-Easy-Switcher-Windows.exe`をダウンロードします。
2. EXEをダブルクリックします。コマンドプロンプトは表示されません。
3. SmartScreen警告が表示された場合、GitHubからダウンロードしたことを確認します。
4. 必要な場合だけ「詳細情報」→「実行」を選びます。

Windows版はコード署名証明書による署名を行っていません。GitHub以外から入手したEXEは
実行しないでください。Windows実機での初回検証では、起動・状態確認・モデル一覧確認を
先に行い、入力途中のCodexセッションがない状態で切り替えを試してください。

## Ollama未導入のPCでセットアップする

1. 本アプリを起動し、画面上部が「Ollama: 未インストール」になっていることを確認します。
2. 「Ollama モデル管理」タブを開き、「Ollama公式ダウンロード」を押します。
3. 開いたOllama公式サイトからWindows版をダウンロードします。
4. ダウンロードしたOllamaインストーラーを実行します。
5. 本アプリへ戻り、「状態を再確認」を押します。
6. 「Ollama: 起動中（バージョン）」と表示されれば準備完了です。
7. PCメモリに合うモデルカードを選び、確認画面からモデルをダウンロードします。

本アプリはOllamaのインストーラーを自動実行しません。公式ページを開くところまでを行います。
この手順はOllamaとモデルを削除したWindows PCで、2026年8月20日に実機確認済みです。

## Ollamaモデルを変更する

1. メイン画面の「モデルを変更」を押します。
2. 最新のインストール済みモデル一覧が自動で再取得されるまで待ちます。
3. 「Codex対応」と表示されたモデルを選び、「選択したモデルを使う」を押します。
4. メイン画面で選択中のモデル名を確認します。
5. 「選択中のOllamaモデルで起動」を押します。

モデルを選んだだけではCodex Appは再起動しません。

Ollamaが停止中の場合は「Ollamaを起動して続けますか？」と表示されます。「はい」を選ぶと
Ollamaを起動し、最大15秒だけ接続を待ってからモデル一覧を取得します。15秒以内に接続できない
場合は処理を終了し、起動エラーを表示します。

## ローカルモデルを選ぶ

モデル一覧には、Ollamaが報告したtools・thinking・コンテキスト長から判定した状態が表示されます。
「Ollama体験用」や「未確認」のモデルは「選択不可」と表示され、Codex用には選択できません。

**1.** 「モデルを変更」を押します。

**2.** 「ローカルモデル」タブから選びます。

**3.** 互換性表示と警告を確認して選択します。

**4.** メイン画面の「選択中のOllamaモデルで起動」を押します。

## モデル名を手動入力する

1. 「モデルを変更」を押し、「モデル名を手動入力」に入力します。
2. 「入力したモデルを選ぶ」を押します。
3. 未準備と表示された場合は「Ollama モデル管理」タブでインストールします。

安全のため、モデル名はOllama公式ライブラリで確認してください。
公式ページの灰色のコード欄から`ollama run gemma3:1b`のようなコマンド全体をコピーし、
入力欄へそのまま貼り付けることもできます。アプリがモデル名だけを取り出します。

## 勉強会向けモデルをかんたん準備する

1. 「Ollama モデル管理」タブを開きます。
2. 6つの候補からメモリ容量・用途・画像対応を確認して選びます。
3. モデル名をコピーしたい場合は、カード内の「Ollama公式ページ（コマンドをコピー）」を
   押し、公式ページの灰色のコマンド欄をコピーします。
4. 未インストールの場合はモデル名と容量を確認して「はい」を押します。
5. Codex対応と判定されたモデルだけがCodex App用として自動選択されます。
6. 「Codex App かんたん切り替え」タブへ戻り、
   「選択中のOllamaモデルで起動」を押します。

| モデル | メモリ目安 | 用途・画像対応 | Codex |
|---|---:|---|---|
| `gemma3:1b` | 8GB | 最軽量・テキストのみ・Ollama体験用 | 非対応 |
| `gemma4:e2b-it-qat` | 16GB | 画像対応・軽量 | 対応 |
| `gemma4:e4b-it-qat` | 16～24GB | 画像対応・バランス型 | 対応 |
| `gemma4:12b-it-qat` | 24GB以上 | 画像対応・高性能 | 対応 |
| `qwen3.5:9b` | 16～24GB | 画像対応・tools/thinking対応 | 対応 |
| `qwen3.5:27b` | 32GB以上 | 画像対応・高性能 | 対応 |

メモリ値は目安です。GPU、コンテキスト長、同時起動アプリにより必要量は変わります。
今回のQwen 3.5の2モデルは画像対応ですが、Qwenシリーズの全モデルが画像対応という意味では
ありません。`gemma3:1b`は推論レベルを低くしてもCodexのthinking要件を満たしません。
`gemma3:1b`だけがインストールされている場合、Codex用のモデル選択画面は開かず、
「Codex対応モデルがありません」と案内します。
Codex対応モデルはインストール後に自動選択され、次回起動時にも保存されます。
毎回選び直す必要はありません。

Ollama自体が未インストールの場合は、同じ画面の「Ollama公式ダウンロード」から
公式ページを開けます。

## 任意のモデルをインストールする

モデル選択画面では、インストール済みモデルだけを選択できます。一覧にないモデルを使う場合は、
先にモデル管理画面からインストールします。

1. 「Ollama モデル管理」タブを開きます。
2. 「モデル名 / 公式コマンド」にモデル名を入力します。
3. 「モデルをインストール」を押します。
4. モデル名、種類、注意事項を確認して「はい」を押します。
5. 完了するまでPCを閉じずに待ちます。
6. Codex対応モデルなら自動選択されます。非対応モデルはOllama体験用として一覧に残ります。
7. Codex対応モデルの場合は、メイン画面へ戻り「選択中のOllamaモデルで起動」を押します。

ローカルモデルは数GB以上の通信量とディスク容量を使う場合があります。

## 通常のCodex GPTへ戻す

「通常のCodex GPTで起動」を押します。勉強会終了時や通常利用へ戻るときに使用します。

## ランチャー終了時の確認

Ollama接続状態でランチャーを閉じると、次から選べます。

- **通常のCodexに戻して終了**: 通常状態へ復元して終了します。
- **Ollama状態のまま終了**: 接続状態を維持して終了します。
- **キャンセル**: ランチャーへ戻ります。

## モデル一覧の見方

| 種類 | 説明 |
|---|---|
| Cloud | Ollamaのクラウド側で動作するモデル。機能確認結果も表示します。 |
| ローカル | PCへダウンロードし、PC上で動作するモデル。機能確認結果を表示します。 |

## 困ったとき

### 選択したモデルで起動できない

「Ollama モデル管理」タブでモデルが一覧にあるか確認します。Cloudモデルの場合はOllamaへの
サインイン状態とインターネット接続も確認してください。

### ローカルモデルでCodexが正常に動かない

「通常のCodex GPTで起動」を押して通常状態へ戻すか、モデル変更画面で別の
「Codex対応」モデルを選んでください。

### Ollamaが見つからない

画面の「Ollama公式ダウンロードページを開く」を押し、Ollamaをインストールしてください。

### Ollamaが停止中と表示される

Ollamaはインストール済みですが、ローカルサーバーが動いていません。モデル一覧更新、
モデルインストール、Codex切り替えのいずれかを押し、確認画面で「はい」を選んでください。
アプリがOllamaを起動して接続を確認します。

### 「インストール済みモデルを再取得しています」のまま進まない

モデル一覧は8秒、各モデルの機能確認も1件につき8秒で打ち切ります。モデル数が多い場合は
確認に時間がかかりますが、モデルが1～2件なのに1分以上変化しない場合は正常ではありません。
本アプリを閉じ、Ollamaを完全終了してから本アプリを起動し直し、モデル操作時の確認画面で
Ollamaを起動してください。

### unknown integration: codex-app と表示される

Ollamaをv0.24.0以降へ更新してください。

### 初回起動時にmacOSがアプリを開けない

アプリを右クリックして「開く」を選択してください。この配布版はApple公証を行っていません。

### Windows SmartScreenが表示される

Windows版EXEはコード署名証明書による署名を行っていないため、警告される場合があります。
GitHubの最新版Releaseからダウンロードしたことを確認し、必要に応じてRelease掲載のSHA256と
一致することを確認してから実行してください。

### WindowsでCodex Appを閉じられない

安全のため強制終了は行いません。Codex Appを手動で閉じてから、もう一度切り替えボタンを
押してください。

## 安全に使うための注意

- 接続切り替え前に、Codex Appの入力途中の内容を確認してください。
- 切り替え直前に`config.toml`は`%LOCALAPPDATA%\CodexModelLauncher\backups`へ
  自動バックアップされます。バックアップ失敗時は切り替えを中止します。
- ローカルモデルのインストール前に、通信量と空きディスク容量を確認してください。
- モデル名はOllama公式ライブラリから確認してください。
- 業務上の機密情報をCloudモデルへ送信する場合は、所属組織のルールに従ってください。
